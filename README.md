# مشروع Kali Linux على GitHub Codespaces

هذا المشروع يوفر بيئة Kali Linux كاملة مع واجهة رسومية (XFCE) وأدوات اختبار الاختراق الأساسية، قابلة للتشغيل مباشرة على GitHub Codespaces.

## الميزات:

*   **Kali Linux Rolling:** أحدث إصدار من Kali Linux.
*   **واجهة رسومية (XFCE):** تجربة سطح مكتب كاملة.
*   **أدوات اختبار الاختراق الأساسية:** تتضمن `nmap`, `amass`, `wfuzz`, `whatweb`, `subfinder`, `httpx`, `nuclei`.
*   **VNC Server:** للوصول إلى الواجهة الرسومية عبر متصفح الويب أو عميل VNC.
*   **SSH Server:** للوصول عبر سطر الأوامر.

## كيفية الاستخدام:

### 1. إنشاء مستودع جديد (Repository):

*   قم بإنشاء مستودع GitHub جديد (يمكن أن يكون عامًا أو خاصًا).
*   استنسخ هذا المستودع إلى جهازك المحلي:
    ```bash
    git clone <رابط المستودع الخاص بك>
    cd <اسم المستودع>
    ```

### 2. إضافة ملفات المشروع:

*   قم بإنشاء مجلد باسم `.devcontainer` في جذر المستودع الخاص بك.
*   داخل مجلد `.devcontainer`، قم بإنشاء الملفات التالية:
    *   `Dockerfile` (محتوياته موجودة في هذا المشروع)
    *   `devcontainer.json` (محتوياته موجودة في هذا المشروع)
    *   `vnc_startup.sh` (محتوياته موجودة في هذا المشروع)

    أو ببساطة، قم بنسخ المجلد `.devcontainer` بالكامل من هذا المشروع إلى المستودع الجديد الخاص بك.

*   قم برفع الملفات إلى مستودعك على GitHub:
    ```bash
    git add .
    git commit -m "Add Kali Linux Codespace configuration"
    git push origin main
    ```

### 3. تشغيل GitHub Codespace:

*   بعد رفع الملفات، انتقل إلى مستودعك على GitHub في متصفح الويب.
*   انقر على الزر الأخضر **`<> Code`**.
*   اختر علامة التبويب **`Codespaces`**.
*   انقر على **`Create codespace on main`**.

    سيقوم GitHub بإنشاء بيئة Codespace جديدة بناءً على ملفات `Dockerfile` و `devcontainer.json` التي قمت بتوفيرها. قد يستغرق هذا بضع دقائق في المرة الأولى حيث يتم بناء صورة Docker.

### 4. الوصول إلى الواجهة الرسومية (GUI) عبر VNC:

بمجرد تشغيل Codespace، يمكنك الوصول إلى الواجهة الرسومية (XFCE) عبر VNC:

*   في واجهة Codespace في متصفحك، انقر على أيقونة **`Ports`** في الشريط الجانبي الأيسر (عادةً ما تكون أيقونة قابس كهربائي).
*   ابحث عن المنفذ `5901` (VNC).
*   بجانب المنفذ `5901`، ستجد خيارًا لـ **`Open in Browser`** أو **`Open in VS Code`**. اختر **`Open in Browser`**.
*   سيتم فتح علامة تبويب جديدة في متصفحك تعرض واجهة VNC. كلمة المرور الافتراضية لـ VNC هي `password`.

    **ملاحظة هامة:** لأسباب أمنية، يفضل تغيير كلمة مرور VNC الافتراضية بعد تشغيل Codespace. يمكنك القيام بذلك داخل بيئة Kali Linux باستخدام الأمر `vncpasswd`.

### 5. الوصول عبر SSH:

يمكنك أيضًا الوصول إلى Codespace عبر SSH:

*   تأكد من تثبيت [GitHub CLI](https://cli.github.com/) على جهازك المحلي.
*   قم بتسجيل الدخول إلى GitHub CLI:
    ```bash
    gh auth login
    ```
*   لعرض Codespaces المتاحة:
    ```bash
    gh codespace list
    ```
*   للاتصال بـ Codespace الخاص بك عبر SSH (استبدل `NAME` باسم Codespace الخاص بك):
    ```bash
    gh codespace ssh --codespace NAME
    ```

## تخصيص الأدوات:

يمكنك تعديل `Dockerfile` لإضافة أو إزالة الأدوات التي تحتاجها. ابحث عن الأقسام التي تحتوي على `RUN apt install -y` و `RUN go install` وقم بتعديلها حسب متطلباتك.
